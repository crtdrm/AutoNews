- 本地网页后台：<http://127.0.0.1:3000>。

## 平时怎样打开和关闭

在项目根目录双击：

| 文件 | 作用 |
| --- | --- |
| `打开AutoNews.command` | 启动生产后台并用默认浏览器打开网页；重复打开会复用现有后台 |
| `停止AutoNews.command` | 停止网页后台，保留配置、数据库和视频文件 |
| `检查AutoNews环境.command` | 显示后台状态和环境检查结果 |

网页进程由当前登录用户的 macOS `launchd` 管理，关闭启动用的终端窗口后仍会继续运行。服务配置放在项目的 `storage/service/`，没有安装开机或登录自启项；重启电脑或退出系统登录后，再双击打开脚本即可。

停止脚本只关闭网页后台。已派生的独立新闻任务需在任务页面或通过 CLI 单独取消。

也可以在项目根目录执行：

```bash
node scripts/local-web.mjs start --open
node scripts/local-web.mjs status
node scripts/local-web.mjs stop
```

后台固定监听 `127.0.0.1:3000`。如果端口已被其他程序占用，启动脚本会提示错误，不会结束其他程序。

## 模型配置与生成视频前的准备

### 1. 大模型

本机已启用 `codex` 适配器，五个文本处理阶段均使用当前 Codex 配置中的 `gpt-6.1-sol`。后续每次新闻处理都是独立调用，连接与凭据由 Codex 自行读取，无需把密钥复制到项目。

本机实际配置位于 **`config/settings.local.yaml`**。该文件存在时，网页、CLI 和独立任务均优先读取这份完整配置，网页保存设置也写回该文件；没有此文件时则读取上游的 `config/settings.yaml`。本机配置不提交 Git，默认配置与离线测试保持独立。

配置项：

- `clis`：工具路径、适配方式、命令参数模板与 JSON 解析方式。
- `ai.stages`：选题、总结、润色、核查和编排各自使用的工具与模型。

后台「系统设置」可以修改各阶段模型。Codex 适配器通过标准输入传入新闻与完整输出字段约束、通过结果文件接收 JSON，再由本地规则检查字段、数值范围和文本长度；每次调用关闭项目操作说明、Shell、应用、插件和多代理功能，并使用只读模式。

如果换电脑，可先复制 `config/settings.yaml` 为 `config/settings.local.yaml`，再按 `config/codex.example.yaml` 的片段配置 `clis.codex` 与 `ai.stages`。`bin` 需填写本机 Codex 的实际可执行路径。模型与连接必须已经在那台电脑上的 Codex 中可用。

环境检查中的 Codex 检查只确认程序可执行。真实模型连通性已经另外验证；以后账号、代理服务或网络改变时，仍可能需要重新检查实际调用。

### 2. 真实配音

上游仅实现了 `silent` 配音组件，会按字数产生静音音频。环境检查显示该组件通过，只代表测试音频接口可用，不代表已经具备真人或合成语音播报能力。

真实声音需要按 `packages/tts/src/types.ts` 的 `TtsProvider` 接口接入本地或云端 TTS，并注册到服务后再修改 `tts.provider`。仅填写一个提供方名称或 API Key 不会自动启用尚未实现的引擎。

### 3. B 站登录（仅在需要投稿时）

已安装 `biliup-cli 0.2.4`，在项目根目录执行：

```bash
npm run aidaily -- bili login
```

按提示本人扫码。凭据默认保存在 `storage/secrets/bilibili-cookies.json`，不提交至 GitHub。发布方式保留上游的人工审核模式。

## 后续更新或重新安装

先停止网页，在项目根目录执行：

```bash
git fetch upstream
git merge upstream/main
npm ci
npm run build
npm ci --prefix templates/daily-deck
npm run build --prefix templates/daily-deck
npx playwright install chromium
```

完成后再次打开启动脚本。`origin` 指向自己的 Fork，`upstream` 指向原作者仓库。

部署脚本依赖 macOS 当前用户的图形登录会话、Node.js 24 以上版本及项目构建产物；换电脑时还需安装 FFmpeg / ffprobe 和所选的模型、配音与投稿工具。
